# Employee Recognition Data Platform

## Objective

Build an end-to-end cloud data engineering platform for
processing employee recognition data.

## Technology Stack

- Azure Data Factory
- Azure Data Lake Storage Gen2
- Azure Databricks
- PySpark
- Delta Lake
- SQL
- MLflow
- GenAI
- RAG
- GitHub

## Architecture

Source
  ↓
Azure Data Factory
  ↓
ADLS Gen2
  ↓
Bronze
  ↓
Databricks / PySpark
  ↓
Silver
  ↓
Gold
  ↓
Analytics / ML / GenAI
